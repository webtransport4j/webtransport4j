ℹ️
Why Both L4 and L7 Heartbeats are Required in WebTransport:
Under RFC 9297, multiple independent WebTransport application sessions can multiplex across a single underlying QUIC UDP connection. An L4 QUIC PING only tells you the physical network route and UDP socket are intact. It does not confirm whether a specific WebTransport application session or worker event loop is healthy or stalled. The L7 Application Heartbeat provides end-to-end application liveness, keeping individual session state active in the WebTransport server registry.
